## 7. Known gaps and risks

- **Phase 1 is not committed.** A lost working tree would lose all of it. Commit first.
- **Printouts** do not yet use the new header, footer, Hindi text or logo.
- **Lab documents** access (D6) is not decided; the current code lets reception open documents, which needs confirming.
- **Doctor read scope** (D2) is open. The current code lets every doctor read every chart.
- **Browser checks** were done in one built-in browser at one window size, not on clinic PCs. Not checked on the Epson A4 printer.
- **Node version on the server** must be 22 or newer. Use the same major version as the dev machine (26) to avoid driver rebuild issues.
- **Old v3 tests** (`backend/tests`, pytest) still exist but are no longer maintained. Do not treat them as a green signal for the new app.
- **Test isolation:** the new app's tests use temp directories, so they are safe, but never point `KH_DATA_DIR` at a real data folder. Never run tests on the hospital server.
- **Demo server:** a background `node server.js` on port 3100 may still be running with synthetic data from `scratchpad\demo-data`. Stop it when finished.
- **Data safety:** the downloaded folder `C:\Users\147ha\Downloads\workspace-dr-sr\data\` holds a live database, encryption keys and a backup. It must not be copied into the repo, committed or reused.
