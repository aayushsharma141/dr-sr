# Plan 17-01: Offline LAN Deployment Engine & Packaging Bundle

## Purpose
Build the complete offline deployment packaging and installer scripts for Kalyan Hospital's central LAN server PC. The installation must execute with zero external internet access and zero Node.js runtime on the server PC.

## Requirements Covered
- `DEP-01`: One-time offline server installation, wheelhouse dependency bundle, built frontend SPA distribution, zero-internet LAN operation.

## Proposed Changes
1. `scripts/build_offline_bundle.py`:
   - Builds frontend production assets using `npm run build`.
   - Packages dependencies into an offline wheelhouse directory.
2. `deploy/install.ps1`:
   - Windows PowerShell installer script:
     - Detects local Python 3.12 installation.
     - Creates isolated virtual environment `backend\.venv`.
     - Installs dependencies from wheelhouse or requirements with `--no-index`.
     - Validates PostgreSQL connection for `kalyan_owner` and `kalyan_app`.
     - Executes Alembic migrations to head revision.
     - Sets up data directories (`backend/var/photos`, `backend/var/backups`, `backend/var/logs`).
3. `deploy/start-server.bat` and `deploy/stop-server.bat`:
   - Starts Uvicorn server on `0.0.0.0:8000` with production logging and background daemon support.
   - Provides safe shutdown command.
4. `deploy/.env.production.template`:
   - Pre-configured production environment template for offline LAN.
