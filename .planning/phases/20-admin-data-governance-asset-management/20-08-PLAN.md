    Create `backend/tests/test_phase20_gate.py` covering the complete Phase 20 integration contract:
    1. **Permissions Enforcement**:
       - Assert Admin can call `/api/admin/patients/{id}/demographics`, `/api/admin/assets`, `/api/admin/templates`, `/api/admin/imports`, `/api/admin/exports`.
       - Assert Reception and Doctor receive 403 Forbidden on all these endpoints.
       - Assert Admin receives 403 on Reception's `PATCH /api/patients/{id}` (verifying Admin lacks `patient:update`).
    2. **Demographic Correction & Snapshot Isolation**:
       - Create patient, record payment, create prescription, finalise encounter.
       - Admin submits demographic correction with reason "Court-ordered name correction".
       - Verify patient record is updated and `PATIENT_CORRECTED` audit event is recorded with diff.
       - Verify `payment.patient_name`, `prescription.patient_name`, and `clinical_encounter.patient_name` snapshot values remain unchanged.
       - Verify payments tamper prevention trigger blocks manual direct updates to snapshot columns.
    3. **Hospital Asset Management**:
       - Upload PNG logo crest via `POST /api/admin/assets`. Verify `ASSET_UPLOADED` audit event.
       - Call `GET /api/assets/active-logo` with no auth session; assert valid image bytes returned.
       - Deactivate asset; assert `is_active` is False, but file remains on disk and row remains in DB.
       - Run `check_asset_storage_integrity()`; assert clean integrity report.
       - Run `create_backup_bundle()`; assert `assets/` and `assets_manifest` are present in archive.
    4. **Print Templates**:
       - Fetch `/api/admin/templates`, patch prescription header/footer with Hindi and English strings.
       - Verify version increments to 2 and `PRINT_TEMPLATE_UPDATED` audit event is logged.
       - Assert stale version yields HTTP 409 `version_conflict`.
    5. **Patient Import Pipeline**:
       - Generate synthetic CSV with 3 rows (1 valid, 1 duplicate mobile+address, 1 missing required guardian).
       - Stage batch; inspect; map; validate; resolve duplicate as 'SKIP'.
       - Commit batch; verify pre-commit backup occurs; verify exactly 1 patient committed with newly minted `KH-YYYY-XXXX` URN.
       - Verify no URN gaps occurred; verify error CSV download contains the 2 skipped/invalid rows with reasons.
       - Verify `PATIENT_IMPORT_STAGED` and `PATIENT_IMPORT_COMMITTED` audit events.
    6. **Patient Export Streaming**:
       - Request export with formula injection string `=1+2` in patient address.
       - Assert output streams without error and contains `'=1+2` (single quote prepended).
       - Verify `PATIENT_EXPORTED` audit event is recorded with reason and row count.
