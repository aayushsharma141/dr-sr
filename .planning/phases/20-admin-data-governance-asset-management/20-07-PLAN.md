<objective>
Build the Patient Export Centre providing permission-checked, field-selective, formula-sanitized, audited dataset streaming in CSV and XLSX formats per D-20-15 through D-20-20, and record the D-04 / EG-7 clinical export governance reversal.

Deliverables:
1. `export_service.py` providing:
   - Dynamic dataset querying scoped by registration/visit date range, department (patients with appointments in department within window per D-20-19), and patient search query.
   - Field selection matrix covering core demographics, administrative fields, profile notes (unticked by default per D-20-18), and complete clinical content (unticked by default per D-20-16).
   - Spreadsheet formula injection neutralization (prefixing cells beginning with `=`, `+`, `-`, or `@` with `'`).
   - Direct streaming response generation in CSV (UTF-8) and XLSX formats with zero server disk persistence (D-20-20).
2. Endpoint `POST /api/admin/exports` guarded by `require(Permission.PATIENT_EXPORT)` per D-20-01, recording `PATIENT_EXPORTED` in the audit log (D-20-17).

4. Frontend `PatientExportDialog.tsx` and `PatientExportPage.tsx` at `/admin/exports` with scope pickers, grouped field checkboxes, amber clinical export warning callout, format selector, and streaming download trigger.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin Client -> Export API | Admin requests bulk extraction of patient records including clinical data; server enforces `patient:export` and writes permanent audit trail |
| Export Data Stream -> Client Spreadsheet Application | Exported values could contain formula injection payloads targeting Excel/Calc users |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-16 | Tampering / Remote Code Execution | `backend/src/kalyan_api/services/export_service.py` | high | mitigate | Sanitize all exported cell text: if a string starts with `=`, `+`, `-`, or `@`, prepend a single quote `'` to prevent automatic spreadsheet formula calculation. |
| T-20-17 | Information Disclosure | `backend/src/kalyan_api/routers/exports.py` | high | mitigate | Enforce `require(Permission.PATIENT_EXPORT)` on server. Enforce mandatory `reason` (`min_length=5`). Record `PATIENT_EXPORTED` in the immutable audit log with user, reason, scope, field list, and row count. Non-admin roles receive 403 Forbidden. |
| T-20-18 | Information Disclosure (Residual Files) | `backend/src/kalyan_api/routers/exports.py` | medium | mitigate | Stream file chunks directly to `StreamingResponse` without saving export files to server disk per D-20-20. |
| T-20-SC | Tampering | npm/pip/cargo installs | high | mitigate | Verify `openpyxl` dependency legitimacy. |
</threat_model>

    1. In `backend/src/kalyan_api/services/audit_service.py`:
       - Add `AuditAction.PATIENT_EXPORTED = "PATIENT_EXPORTED"`.
    2. Create `backend/src/kalyan_api/schemas/exports.py`:
       - `ExportScope`: `start_date: date | None`, `end_date: date | None`, `department_id: int | None`, `search_query: str | None`.
       - `PatientExportRequest`:
         - `reason: str = Field(..., min_length=5, description="Documented export purpose")`
         - `format: Literal['csv', 'xlsx'] = 'csv'`
         - `scope: ExportScope`
         - `fields: list[str]` (allowed values: `full_name`, `urn`, `guardian_name`, `gender`, `age_years`, `mobile`, `address`, `district`, `state`, `emergency_contact`, `legacy_urn`, `allergies`, `notes`, `encounters`, `clinical_notes`, `addenda`, `assessments`, `vitals`, `diagnoses`, `prescriptions`, `treatment_plans`, `sessions`)
    3. Create `backend/src/kalyan_api/services/export_service.py`:
       - `sanitize_cell(val: Any) -> Any`: If `val` is a string starting with `=`, `+`, `-`, or `@`, prepend `'`.
       - Query builder:
         - Base query joins `Patient`.
         - If `scope.department_id` is set, join `Appointment` and filter by `Appointment.department_id == scope.department_id` and appointment date within window (per D-20-19).
         - If `scope.start_date` and `scope.end_date` set, filter by `Patient.created_at` or appointment date.
         - If `scope.search_query` set, filter by name, mobile, URN.
         - Fetch selected fields; if clinical fields requested, eagerly load associated encounters, vitals, prescriptions, sessions.
       - Streaming generators:
         - `generate_csv_stream(rows, selected_fields)`: yields UTF-8 CSV chunks.
         - `generate_xlsx_stream(rows, selected_fields)`: generates `.xlsx` using `openpyxl` in-memory buffer (`io.BytesIO`) and yields bytes chunks.
         - Zero server disk writing (D-20-20).
    4. Create `backend/src/kalyan_api/routers/exports.py`:
       - `POST /api/admin/exports`:
         - Guarded by `require(Permission.PATIENT_EXPORT)`.
         - Validates payload.
         - Calls `export_service.build_export_stream(session, payload)`.
         - Writes `audit_service.record(session, ctx, AuditAction.PATIENT_EXPORTED, "PATIENT_EXPORT", None, after={"scope": payload.scope.model_dump(), "fields": payload.fields, "row_count": count}, reason=payload.reason)`.
         - Returns `StreamingResponse` with appropriate MIME type (`text/csv` or `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`) and `Content-Disposition: attachment; filename="patients_export_YYYYMMDD_HHMMSS.[csv|xlsx]"`.
    5. Register `exports_router` in `backend/src/kalyan_api/main.py`.
    6. Write comprehensive tests in `backend/tests/test_patient_export_api.py`.
  </action>
