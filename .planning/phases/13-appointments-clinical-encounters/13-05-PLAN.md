# Plan 13-05: Frontend Reception Appointment Booking & Daily Queue Board

## Purpose
Build reception appointment booking UI and real-time daily queue management board, supporting patient lookup, doctor selection, atomic token allocation, and quick status transitions.

## Requirements Covered
- `APT-01`: Reception books per-doctor daily appointment with token.
- `APT-02`: Reception tracks appointment statuses (`Booked`, `Arrived`, `Cancelled`, `No-show`).

## Proposed Changes

### 1. API Client Additions (`frontend/src/api/client.ts` & `queries.ts`)
- `useAppointments(params: { date?: string; doctor_id?: number; status?: string })`
- `useBookAppointment()`: mutation calling `POST /api/appointments`
- `useUpdateAppointmentStatus()`: mutation calling `PATCH /api/appointments/{id}/status`

### 2. Frontend Components
- `frontend/src/pages/AppointmentsReception.tsx` (`/reception/appointments`):
  - Date picker (defaults to today).
  - Doctor filter tabs (All Doctors, Dr. Madan Mohan Dwivedi, Dr. Chandan Kr. Dwivedi).
  - Summary stats banner: Total Booked, Arrived (Waiting), In Consultation, Done.
  - "Book New Appointment" button opening booking modal.
  - Interactive table / kanban list of appointments:
    - Token badge (e.g. `#1`, `#2`).
    - Patient URN + Full Name + Mobile.
    - Status badge with color coding (Booked: blue, Arrived: amber, In Consultation: purple, Done: green, Cancelled/No-show: gray).
    - Quick actions: "Mark Arrived", "Cancel Appointment", "Mark No-Show".
- `frontend/src/components/AppointmentBookingModal.tsx`:
  - Patient search input with quick auto-complete (shows URN and mobile).
  - Doctor dropdown populated from active doctors API.
  - Appointment date selector.
  - Notes field.
  - Submits and displays assigned token number in a success prompt.

### 3. Navigation Update
- Add Reception navigation link to `/reception/appointments` in `AreaHome.tsx` and `AppShell.tsx`.

### 4. Tests
- `frontend/src/pages/__tests__/appointments-reception.test.tsx`:
  - Renders appointments list with tokens.
  - Opens booking modal and submits new appointment.
  - Performs "Mark Arrived" status update.
