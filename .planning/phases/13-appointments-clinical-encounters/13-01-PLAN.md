# Plan 13-01: Database Models & Migration 0003

## Purpose
Define SQLAlchemy 2.0 ORM models and generate Alembic revision `0003_appointments_and_clinical_encounters.py` for appointments, daily token counters, clinical encounters, and addenda, with PostgreSQL trigger immutability.

## Requirements Covered
- `APT-01`: Appointments schema with token numbers unique per doctor per date.
- `APT-02`: Appointment status tracking (`BOOKED`, `ARRIVED`, `IN_CONSULTATION`, `DONE`, `CANCELLED`, `NO_SHOW`).
- `CLN-01`: Clinical encounters schema with symptoms, clinical notes, diagnosis, and doctor silo foreign keys.
- `CLN-02`: Immutability flag `is_finalised` and dedicated `clinical_addenda` schema.

## Proposed Changes

### 1. `backend/src/kalyan_api/models.py`
Add models:
- `AppointmentStatus(StrEnum)`: `BOOKED`, `ARRIVED`, `IN_CONSULTATION`, `DONE`, `CANCELLED`, `NO_SHOW`.
- `DailyTokenSequence(Base)`:
  - `doctor_id`: ForeignKey("doctors.id", ondelete="RESTRICT"), primary_key=True
  - `appointment_date`: Date, primary_key=True
  - `last_token`: Integer, default=0, nullable=False
  - `created_at`: DateTime(timezone=True)
  - `updated_at`: DateTime(timezone=True)
- `Appointment(Base)`:
  - `id`: Integer primary_key
  - `patient_id`: ForeignKey("patients.id", ondelete="RESTRICT"), nullable=False, index=True
  - `doctor_id`: ForeignKey("doctors.id", ondelete="RESTRICT"), nullable=False, index=True
  - `appointment_date`: Date, nullable=False, index=True
  - `token_number`: Integer, nullable=False
  - `status`: String(32), default=AppointmentStatus.BOOKED.value, nullable=False, index=True
  - `status_updated_at`: DateTime(timezone=True), nullable=False
  - `cancellation_reason`: Text, nullable=True
  - `notes`: Text, nullable=True
  - `created_by_user_id`: ForeignKey("users.id", ondelete="RESTRICT"), nullable=False
  - `version_id`: Integer, default=1, nullable=False
  - `created_at`, `updated_at`: DateTime(timezone=True)
  - UniqueConstraint: `uq_doctor_date_token` on `(doctor_id, appointment_date, token_number)`
- `ClinicalEncounter(Base)`:
  - `id`: Integer primary_key
  - `appointment_id`: ForeignKey("appointments.id", ondelete="SET NULL"), nullable=True, index=True
  - `patient_id`: ForeignKey("patients.id", ondelete="RESTRICT"), nullable=False, index=True
  - `doctor_id`: ForeignKey("doctors.id", ondelete="RESTRICT"), nullable=False, index=True
  - `encounter_date`: DateTime(timezone=True), nullable=False
  - `symptoms`: Text, nullable=False
  - `clinical_notes`: Text, nullable=False
  - `diagnosis`: Text, nullable=False
  - `is_finalised`: Boolean, default=False, nullable=False
  - `finalised_at`: DateTime(timezone=True), nullable=True
  - `version_id`: Integer, default=1, nullable=False
  - `created_at`, `updated_at`: DateTime(timezone=True)
- `ClinicalAddendum(Base)`:
  - `id`: Integer primary_key
  - `encounter_id`: ForeignKey("clinical_encounters.id", ondelete="RESTRICT"), nullable=False, index=True
  - `doctor_id`: ForeignKey("doctors.id", ondelete="RESTRICT"), nullable=False
  - `addendum_text`: Text, nullable=False
  - `created_at`: DateTime(timezone=True), nullable=False
  - `created_by_user_id`: ForeignKey("users.id", ondelete="RESTRICT"), nullable=False

### 2. Alembic Migration `0003_appointments_and_clinical_encounters.py`
Create migration creating all 4 tables, indices, foreign keys, unique constraint, and PostgreSQL trigger preventing update of finalised encounters.
