<task type="auto">
  <name>Task 1: PBKDF2 Authentication Service & Password Guards</name>
  <files>app/services/auth_service.py</files>
  <read_first>SECURITY.md, app/db/schema.sql, app/db/connection.py</read_first>
  <action>
    1. Implement `AuthService` in `app/services/auth_service.py`:
       - `hash_password(password: str, salt: str | None = None) -> tuple[str, str]`:
         - Uses `hashlib.pbkdf2_hmac('sha256', password.encode('utf-8'), salt.encode('utf-8'), iterations=100000)`.
         - If salt is None, generates 16-byte random hex using `secrets.token_hex(16)`.
         - Returns `(password_hash_hex, salt_hex)`.
       - `verify_password(password: str, stored_hash: str, salt: str) -> bool`:
         - Computes PBKDF2-HMAC-SHA256 with provided salt and compares using `hmac.compare_digest()`.
       - `ensure_default_admin(default_username: str = "admin", default_password: str = "kalyan@admin") -> dict`:
         - Checks if any user exists in `users` table. If empty, creates default admin user (`role = 'ADMIN'`).
       - `authenticate(username: str, password: str) -> dict | None`:
         - Looks up user by username. Verifies password. Returns user dict (omitting hash/salt) on success.
       - `verify_admin_credentials(password: str) -> bool`:
         - Checks if password matches any active user with `role = 'ADMIN'`.
       - `change_password(user_id: int, old_password: str, new_password: str) -> bool`:
         - Validates old password, generates new salt and hash, updates database.
  </action>
  <verify>Unit tests verifying PBKDF2 hash generation, password verification, and default admin seeding.</verify>
  <acceptance_criteria>
    - Password hashing uses 100,000 iterations of PBKDF2-HMAC-SHA256.
    - Timing attacks mitigated via constant-time `hmac.compare_digest`.
    - Default admin account created automatically on first run.
  </acceptance_criteria>
  <done>Authentication service provides secure local password management.</done>
</task>
