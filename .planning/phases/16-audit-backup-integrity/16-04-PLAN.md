# Plan 16-04: Clinical & Financial Integrity Engine

## Purpose
Build an automated integrity inspection engine that audits the entire Kalyan Hospital database and file storage for clinical, financial, and sequential consistency.

## Requirements Covered
- `BAK-03`: Integrity report checking balance-vs-ledger mismatches, URN gaps/duplicates, receipt sequence gaps/duplicates, orphan photo files, session-count discrepancies.

## Proposed Changes

### 1. `backend/src/kalyan_api/services/integrity_service.py`
- `run_integrity_audit(session: Session) -> IntegrityReport`:
  - 1. **Ledger vs Balance Check**: For each active treatment plan, verify `agreed_price_paise - sum(non-reversed payments) >= 0`. Detect any negative dues or overpayments.
  - 2. **Sequential URN Check**: Check for duplicate patient URNs or unexpected gap patterns.
  - 3. **Sequential Receipt Check**: Check for duplicate receipt numbers per sequence cycle.
  - 4. **Session Progress Check**: For each treatment plan, assert `completed_sessions == count(treatment_sessions)` where `is_finalised is True`.
  - 5. **Photo File Integrity Check**: Check disk photos for missing DB patients and DB patient `photo_path` entries pointing to missing files.
  - Record audit event `INTEGRITY_AUDIT_RUN`.

### 2. Automated Tests in `backend/tests/test_integrity_service.py`
- Test clean database reports `is_healthy: True` with all 5 checks passing.
- Test injected discrepancies (orphan file, corrupted session count, duplicate URN) are accurately identified and reported.
