# Plan 16-06: Frontend Audit Log Viewer, Backup Manager & Integrity Dashboard

## Purpose
Build React frontend pages for system administrators to inspect the immutable audit log, manage automated & manual backup archives, trigger restores, and view live system integrity reports.

## Requirements Covered
- `AUD-02`, `BAK-01`, `BAK-02`, `BAK-03`: Web dashboards for Admin role.

## Proposed Changes

### 1. `frontend/src/api/` Updates
- Types: `AuditLogOut`, `AuditLogListResponse`, `BackupOut`, `BackupArchiveOut`, `IntegrityReportOut`.
- Query and mutation hooks: `useAuditLogs`, `useBackups`, `useCreateBackup`, `useRestoreBackup`, `useIntegrityCheck`.

### 2. `frontend/src/pages/admin/AuditViewerPage.tsx`
- Filterable log viewer with user, action, entity type, date range controls.
- Expandable rows showing Before/After JSON diffs.
- Clear outcome and timestamp indicators.

### 3. `frontend/src/pages/admin/BackupManagerPage.tsx`
- Archive list with creation dates, size, manifest metadata, and SHA-256 verification badges.
- One-click "Create New Backup" action button with destination selection.
- "Restore" dialog with confirmation warning and pre-restore snapshot reminder.

### 4. `frontend/src/pages/admin/IntegrityDashboard.tsx`
- Live inspection cards for Ledger Balance, URN sequences, Receipt sequences, Session progress, and Photo storage.
- Real-time "Run Integrity Check" trigger with overall HEALTHY / DISCREPANCIES status banner.

### 5. Wire into `frontend/src/router.tsx`
- `/admin/audit` -> `AuditViewerPage`
- `/admin/backups` -> `BackupManagerPage`
- `/admin/integrity` -> `IntegrityDashboard`

### 6. Automated Tests in `frontend/src/pages/__tests__/`
- `audit-viewer.test.tsx`, `backup-manager.test.tsx`, `integrity-dashboard.test.tsx`.
