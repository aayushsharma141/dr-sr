    1. Implement `PrintService` in `app/services/print_service.py`:
       - `export_to_pdf(html_content: str, output_path: str) -> str`:
         - Uses `QTextDocument` and `QPrinter(QPrinter.PdfFormat)`.
         - Sets page size to `QPageSize(QPageSize.A4)`.
         - Sets page orientation to Portrait and zero/standard margins (10mm).
         - Renders document to destination PDF file path.
         - Returns absolute path of exported PDF.
       - `show_print_preview(html_content: str, parent=None) -> None`:
         - Creates `QPrintPreviewDialog` with standard zoom and print controls.
         - Connects `paintRequested` to render `QTextDocument` onto printer.
       - `print_document(html_content: str, parent=None) -> bool`:
         - Opens standard Windows system `QPrintDialog` allowing user to select physical printer.
