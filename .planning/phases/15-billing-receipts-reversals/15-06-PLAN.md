# Plan 15-06: Frontend Pending Dues Dashboard, Reversal Modal & Patient Timeline

## Purpose
Build Reception/Admin Pending Dues dashboard, Admin Payment Reversal Modal, and the Unified Patient Timeline UI displaying all patient interactions in chronological sequence.

## Requirements Covered
- `BIL-03`, `BIL-05`, `CLN-03`

## Proposed Changes

### 1. `frontend/src/pages/PendingDuesPage.tsx`
- Dashboard for Reception and Admin displaying active treatment packages with pending balances.
- Columns: Patient URN, Patient Name, Mobile, Package Name, Agreed Fee, Total Paid, Pending Balance.
- "Collect Payment" action button opening `PaymentModal`.

### 2. `frontend/src/components/PaymentReversalModal.tsx`
- Admin-only modal for reversing posted payments.
- Displays payment details and requires mandatory justification reason ($\ge 5$ characters).
- Warns that reversal is permanent and logged in the hospital audit trail.

### 3. `frontend/src/components/PatientTimeline.tsx`
- Unified chronological feed component embedded into `PatientDetail.tsx` and accessible to doctors and reception.
- Visual timeline line with icons:
  - 📅 Appointment
  - 🩺 Clinical Encounter
  - 💊 Prescription
  - 📦 Treatment Package
  - ⚡ Physiotherapy Session
  - 💳 Payment / Reversal
- Clickable event cards showing summaries and links to relevant print slips or details.

### 4. Automated Tests in `frontend/src/pages/__tests__/pending-dues.test.tsx` and `timeline.test.tsx`
- Verify pending dues table rendering and collection action.
- Verify reversal modal validation and API submission.
- Verify chronological event sorting in patient timeline.
