# Plan 15-05: Frontend Payment Collection Modal & Thermal/A5 Printable Receipt

## Purpose
Build React components for collecting payments, calculating remaining balances in real-time, and rendering a printable receipt slip supporting 80mm thermal receipt printer and standard A5 paper, with prominent `DUPLICATE` watermark/header on reprints.

## Requirements Covered
- `BIL-01`, `BIL-02`, `BIL-04`

## Proposed Changes

### 1. `frontend/src/api/` Updates
- Types in `types.ts`: `PaymentCreate`, `PaymentOut`, `PendingDueOut`, `PaymentMethod`.
- React Query hooks in `queries.ts`: `usePatientPayments`, `useRecordPayment`, `usePendingDues`, `useReversePayment`.

### 2. `frontend/src/components/PaymentModal.tsx`
- Modal dialog for Reception/Admin to record payments.
- Supports Consultation Fee or Package Instalment.
- For Package Instalment: displays package name, agreed price, amount already paid, and remaining balance. Rejects input exceeding remaining balance.
- Payment method buttons: `CASH`, `UPI`, `CARD`.
- Submits `amount_paise` (converting user input rupees to integer paise).

### 3. `frontend/src/components/ReceiptPrint.tsx`
- Printable receipt component formatted for both standard paper and 80mm POS thermal receipt rolls (`@media print`).
- Header: Kalyan Hospital bilingual letterhead and contact info.
- Receipt details: Receipt number, date & time, patient name, URN, doctor/service name, payment mode, amount in figures and words (`₹...`).
- Prominent `DUPLICATE` stamp/watermark displayed if `is_reprint` is true.

### 4. Automated Tests in `frontend/src/components/__tests__/payment-modal.test.tsx` and `receipt-print.test.tsx`
- Test rupee to paise conversion and balance limit validation.
- Test receipt rendering and duplicate badge on reprint.
