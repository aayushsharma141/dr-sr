           If role is not DOCTOR, return `false()`.
       - Update `get_scoped_or_404(...)`:
         - When loading with `ScopeFamily.CLINICAL_READ` and `principal.role == Role.DOCTOR`:
           Check if the retrieved row has an attribute or column `doctor_id`.
           If `row.doctor_id != principal.doctor_id`:
             Record audit log:
             `audit_service.record_audit_event(session, actor_user_id=principal.user_id, action=AuditAction.CROSS_DOCTOR_CLINICAL_READ, entity_type=target.__name__, entity_id=obj_id, details={"actor_doctor_id": principal.doctor_id, "record_doctor_id": row.doctor_id, "patient_id": getattr(row, "patient_id", None)})`.
