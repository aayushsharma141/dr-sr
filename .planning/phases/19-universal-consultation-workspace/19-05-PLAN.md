<objective>
Execute Wave 5 of Phase 19: implement the complete Universal Consultation Workspace frontend, uniting chief complaints, vitals with live BMI, department-specific clinical forms (Physiotherapy and Ophthalmology), integrated prescription lifecycle management, and follow-up recommendations on a single continuous auto-saving page.

Deliverables:
1. Continuous single-page layout with sticky clinical header, left anchor jump navigation rail, and prior encounter side card with per-section copy controls (D-19-06, D-19-07, D-19-08, DWS-01).
2. Debounced auto-save engine (~3s + onBlur) with server confirmation badge and offline retry handling without browser storage caching (D-19-22, D-19-23, DWS-02).
3. Vitals biometrics component with real-time calculated BMI indicator and category chip (DWS-06).
4. Specialty form components (`SpecialtyPhysiotherapyForm` with VAS 0–10 and `SpecialtyOphthalmologyForm` with side-by-side OD/OS columns) (D-19-10, D-19-11, D-19-12, DWS-05).
5. Integrated prescription authoring section with medicine delivery details (`strength`, `form`, `route`), authorisation confirmation, and cancellation-with-reason modal (D-19-14, D-19-15, D-19-16, D-19-17, DWS-07).
</objective>
