# Plan 08-01: Clinical Records & Financial Integrity

## 1. Goal
Integrate audit trail into `TreatmentService` and `BillingService`, enforce session immutability, and verify integer paise currency arithmetic.

## 2. Tasks

### Task 1: Audit Integration & Immutability in `TreatmentService`
- File: `app/services/treatment_service.py`
  - Inject `AuditService(self.db_path)`.
  - In `open_treatment_case()`: log `CASE_OPENED` audit event with case ID, patient ID, and fee.
  - In `log_session()`: log `SESSION_LOGGED` audit event with session ID, case ID, therapist, and pain score.
  - In `update_case_status()`: log `CASE_STATUS_UPDATED` audit event.
  - Guarantee append-only nature (confirm no update/delete session exposed).

### Task 2: Audit Integration in `BillingService`
- File: `app/services/billing_service.py`
  - Inject `AuditService(self.db_path)`.
  - In `record_installment()`: log `PAYMENT_RECORDED` audit event with payment ID, case ID, amount formatted, and payment mode.

### Task 3: Automated Verification
- Update `tests/test_treatment_service.py` and `tests/test_billing_service.py` with audit verification tests.
- Run full pytest test suite.

## 3. Verification Criteria
- All tests in `tests/test_treatment_service.py` and `tests/test_billing_service.py` pass.
- Full test suite passes 100% green.
