# Plan 14-01: Database Models & Migration 0004

## Purpose
Define SQLAlchemy 2.0 ORM models and generate Alembic revision `0004_prescriptions_and_treatment_records.py` for prescriptions, prescription items, treatment plans, physiotherapy sessions, and session addenda, with PostgreSQL trigger immutability.

## Requirements Covered
- `RX-01`: Structured prescription schema linked to patient and doctor.
- `TRT-01`: Treatment plan/package schema with condition, referral source, total sessions, and agreed fee in integer paise.
- `TRT-02`: Physiotherapy treatment sessions schema with sequential numbering and VAS pain score (0–10).
- `TRT-03`: Immutability flag `is_finalised` and dedicated `treatment_session_addenda` schema with database trigger.

## Proposed Changes

### 1. `backend/src/kalyan_api/models.py`
Add models:
- `TreatmentPlanStatus(StrEnum)`: `ACTIVE`, `COMPLETED`, `CANCELLED`.
- `TreatmentPlan(Base)`:
  - `id`: Integer primary_key
  - `patient_id`: ForeignKey("patients.id", ondelete="RESTRICT"), nullable=False, index=True
  - `doctor_id`: ForeignKey("doctors.id", ondelete="RESTRICT"), nullable=False, index=True
  - `encounter_id`: ForeignKey("clinical_encounters.id", ondelete="SET NULL"), nullable=True, index=True
  - `plan_name`: String(128), nullable=False
  - `condition_diagnosis`: Text, nullable=False
  - `referred_by`: String(128), nullable=True
  - `total_sessions`: Integer, nullable=False
  - `completed_sessions`: Integer, default=0, nullable=False
  - `agreed_price_paise`: BigInteger, nullable=False
  - `status`: String(32), default=TreatmentPlanStatus.ACTIVE.value, nullable=False, index=True
  - `cancellation_reason`: Text, nullable=True
  - `version_id`: Integer, default=1, nullable=False
  - `created_at`, `updated_at`: DateTime(timezone=True)
- `TreatmentSession(Base)`:
  - `id`: Integer primary_key
  - `treatment_plan_id`: ForeignKey("treatment_plans.id", ondelete="RESTRICT"), nullable=False, index=True
  - `patient_id`: ForeignKey("patients.id", ondelete="RESTRICT"), nullable=False, index=True
  - `doctor_id`: ForeignKey("doctors.id", ondelete="RESTRICT"), nullable=False, index=True
  - `session_number`: Integer, nullable=False
  - `session_date`: Date, default=func.current_date(), nullable=False, index=True
  - `vas_score`: Integer, nullable=False (check: `0 <= vas_score <= 10`)
  - `modalities`: JSONB, default=list, nullable=False
  - `clinical_notes`: Text, nullable=False
  - `is_finalised`: Boolean, default=True, nullable=False
  - `created_by_user_id`: ForeignKey("users.id", ondelete="RESTRICT"), nullable=False
  - `created_at`: DateTime(timezone=True)
  - UniqueConstraint: `uq_plan_session_number` on `(treatment_plan_id, session_number)`
- `TreatmentSessionAddendum(Base)`:
  - `id`: Integer primary_key
  - `session_id`: ForeignKey("treatment_sessions.id", ondelete="RESTRICT"), nullable=False, index=True
  - `author_user_id`: ForeignKey("users.id", ondelete="RESTRICT"), nullable=False
  - `note`: Text, nullable=False
  - `created_at`: DateTime(timezone=True)
- `Prescription(Base)`:
  - `id`: Integer primary_key
  - `patient_id`: ForeignKey("patients.id", ondelete="RESTRICT"), nullable=False, index=True
  - `doctor_id`: ForeignKey("doctors.id", ondelete="RESTRICT"), nullable=False, index=True
  - `encounter_id`: ForeignKey("clinical_encounters.id", ondelete="SET NULL"), nullable=True, index=True
  - `diagnosis`: Text, nullable=False
  - `dietary_advice`: Text, nullable=True
  - `general_advice`: Text, nullable=True
  - `follow_up_date`: Date, nullable=True
  - `version_id`: Integer, default=1, nullable=False
  - `created_at`, `updated_at`: DateTime(timezone=True)
- `PrescriptionItem(Base)`:
  - `id`: Integer primary_key
  - `prescription_id`: ForeignKey("prescriptions.id", ondelete="CASCADE"), nullable=False, index=True
  - `item_order`: Integer, nullable=False
  - `medicine_name`: String(128), nullable=False
  - `dosage`: String(64), nullable=False
  - `frequency`: String(64), nullable=False
  - `duration_days`: Integer, nullable=False (check: `1 <= duration_days <= 365`)
  - `instructions`: Text, nullable=True
  - UniqueConstraint: `uq_prescription_item_order` on `(prescription_id, item_order)`

### 2. Alembic Migration `0004_prescriptions_and_treatment_records.py`
Create migration creating all 5 tables, check constraints, foreign keys, unique indices, and the PostgreSQL trigger `prevent_finalised_treatment_session_tampering` to prevent modification or deletion of finalized sessions.
