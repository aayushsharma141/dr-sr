# Plan 14-06: Frontend Treatment Plan & Session Logger UI

## Purpose
Build treatment package management workspace, interactive session logger with VAS pain slider, and retrospective addenda modal (`TRT-01`, `TRT-02`, `TRT-03`).

## Requirements Covered
- `TRT-01`: Treatment plan creation and progress tracking.
- `TRT-02`: Session logging with VAS score 0–10 and modalities.
- `TRT-03`: Immutable session history and addenda append.

## Proposed Changes

### 1. `frontend/src/api/types.ts` & `frontend/src/api/queries.ts`
- Domain types for `TreatmentPlanOut`, `TreatmentPlanCreate`, `TreatmentSessionOut`, `TreatmentSessionCreate`, `TreatmentSessionAddendumCreate`.
- Hooks: `useTreatmentPlans`, `useTreatmentPlan`, `useCreateTreatmentPlan`, `useTreatmentSessions`, `useLogSession`, `useAddSessionAddendum`.

### 2. `frontend/src/pages/TreatmentPlanWorkspace.tsx`
- Active package card showing progress gauge (e.g. Session 3 of 10 completed).
- Action buttons: "Log Session #4", "Create New Plan", "Cancel Plan".
- Chronological session timeline with VAS badge and modality chips.

### 3. `frontend/src/components/SessionLoggerModal.tsx`
- Interactive VAS Pain Score slider ($0 \text{ to } 10$) with descriptive color gradient and label ($0=\text{No Pain}$, $5=\text{Moderate}$, $10=\text{Severe Unbearable}$).
- Modality checkboxes (IFT, Ultrasound, Traction, TENS, Hot Pack, Exercise).
- Therapist clinical notes and submit action.

### 4. `frontend/src/components/SessionAddendumModal.tsx`
- Addendum submission form with explanation note.

## Verification
- Frontend unit tests: `frontend/src/pages/__tests__/treatment-plan-workspace.test.tsx`
  - Verifies package creation, session logging with VAS score, addendum append, and completed package state.
