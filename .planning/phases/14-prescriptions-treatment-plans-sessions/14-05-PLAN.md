# Plan 14-05: Frontend Prescriptions Workspace & Print Slip

## Purpose
Build doctor prescription authoring interface, dynamic medicine item controls, and bilingual printable prescription view matching client hospital slip format (`RX-01`).

## Requirements Covered
- `RX-01`: Doctor prescription issuance with printable bilingual slip.

## Proposed Changes

### 1. `frontend/src/api/types.ts` & `frontend/src/api/queries.ts`
- Domain types for `PrescriptionCreate`, `PrescriptionOut`, `PrescriptionItemCreate`, `PrescriptionItemOut`.
- React Query hooks: `usePrescriptions`, `usePrescription`, `useCreatePrescription`.

### 2. `frontend/src/pages/PrescriptionWorkspace.tsx`
- Multi-row medication table with controls to Add Item and Remove Item.
- Inputs for Medicine Name, Dosage, Frequency (presets: "1-0-1", "1-0-0", "0-0-1", "TDS", "SOS"), Duration in days, and Instructions.
- Diagnosis, general advice, dietary guidance, and follow-up date picker.

### 3. `frontend/src/components/PrescriptionPrint.tsx`
- Printable A4 layout with `@media print` rules.
- Header: Bilingual hospital letterhead from clinic settings.
- Patient Banner: URN, Full Name, Age/Sex, Date, Doctor Name & Registration Number.
- Rx Symbol and English medicine table with static Hindi Devanagari labels.
- Dual signature line.

## Verification
- Frontend unit tests: `frontend/src/pages/__tests__/prescription-workspace.test.tsx`
  - Verifies form interaction, item addition/removal, submission to API, and print trigger.
