# Plan 09-01: Local Security & Verified Disaster Recovery

## 1. Goal
Implement named `DOCTOR` role in `AuthService` and build unified disaster recovery bundling both SQLite database and patient photos in `BackupService`.

## 2. Tasks

### Task 1: Named User Roles & Permissions in `AuthService`
- File: `app/services/auth_service.py`
  - Add `create_user(username, password, role="RECEPTIONIST", actor_name="Admin") -> dict`.
  - Validate role is in `("ADMIN", "RECEPTIONIST", "DOCTOR")`.
  - Add permission helpers: `can_manage_backups(role)`, `can_manage_users(role)`, `can_record_clinical_sessions(role)`.
  - Log `USER_CREATED` to `AuditService`.

### Task 2: Unified Backup Bundle (DB + Photos) in `BackupService`
- File: `app/services/backup_service.py`
  - In `create_backup(target_dir=None, bundle_photos=True)`:
    - Atomically snapshots active SQLite database.
    - Archives `kalyan.db` and all image files from `PHOTOS_DIR` into a timestamped `.kalyan_bak` (zip format) with a `manifest.json`.
    - If `bundle_photos=False`, retains standalone `.db` file format for backward compatibility.
  - In `verify_backup_integrity(path)`:
    - Detects whether file is `.kalyan_bak` / `.zip` or `.db`.
    - Inspects database integrity and canonical table structure.
    - Counts and reports bundled photo count and total uncompressed size.
  - In `restore_from_backup(path)`:
    - Safely creates a rollback snapshot of both live database and current `PHOTOS_DIR`.
    - Restores the SQLite database via atomic backup.
    - Safely unpacks photos into `PHOTOS_DIR` guarding against zip path traversal.
    - Rolls back both database and photos if post-restore verification fails.

### Task 3: Automated Verification
- Update `tests/test_auth_service.py` to test `DOCTOR` role creation and permission checking.
- Update `tests/test_backup_service.py` to test unified backup creation, photo bundling, and verified restore with photo recovery.
- Run full pytest test suite.

## 3. Verification Criteria
- All tests in `tests/test_auth_service.py` and `tests/test_backup_service.py` pass.
- Full test suite passes 100% green.
