# Plan 10-01: Real Windows Handover & Offline Verification

## 1. Goal
Build the Windows desktop executable, execute end-to-end rehearsal simulation with zero network connectivity, verify A4 printout fidelity, and validate complete disaster recovery.

## 2. Tasks

### Task 1: Standalone Windows Executable Build
- Run PyInstaller via `.venv\Scripts\pyinstaller.exe KalyanHospital.spec --noconfirm`.
- Verify `dist/KalyanHospital/KalyanHospital.exe` is generated with required schema and assets.

### Task 2: End-to-End Offline Rehearsal Script
- Create `tests/test_offline_rehearsal_e2e.py`:
  - Enforce zero network connectivity using monkeypatched socket connections.
  - Setup administrator account.
  - Create doctor account (`dr_dwivedi`).
  - Register patient with complete demographics and photo.
  - Open treatment case and log dated therapy session with pain score.
  - Record payment installment in integer paise and verify remaining balance.
  - Generate A4 registration card HTML and assert all 12 fields + dual signatures.
  - Create unified `.kalyan_bak` backup containing database and photos.
  - Simulate catastrophic data wipe.
  - Execute verified restore from `.kalyan_bak`.
  - Validate 100% data and photo restoration and check audit trail logs.

### Task 3: Regression Suite Execution
- Run `pytest` on all tests.
- Verify 100% test pass rate.

## 3. Verification Criteria
- `dist/KalyanHospital/KalyanHospital.exe` exists and is non-empty.
- `tests/test_offline_rehearsal_e2e.py` passes.
- Pytest suite passes 100% green.
