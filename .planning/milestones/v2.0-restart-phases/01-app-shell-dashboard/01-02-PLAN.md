    1. Implement `DashboardService` in `app/services/dashboard_service.py` taking an optional `db_path`:
       - `get_statistics() -> dict`:
         - `total_patients`: `SELECT COUNT(*) FROM patients WHERE status != 'ARCHIVED'`
         - `today_registrations`: `SELECT COUNT(*) FROM patients WHERE date(registered_at) = date('now', 'localtime')`
         - `active_cases`: `SELECT COUNT(*) FROM treatment_cases WHERE status = 'IN_PROGRESS'`
         - `total_pending_balance_paise`: Sum of `total_amount_paise` for active cases minus sum of `amount_paid_paise` on those cases.
       - Return values in structured format:
         ```python
         {
             "total_patients": int,
             "today_registrations": int,
             "active_cases": int,
             "pending_balance_rupees": float,
             "pending_balance_paise": int
         }
         ```
       - Gracefully handle empty tables returning 0, never crashing on nulls.
  </action>
  <verify>Unit test querying `DashboardService` against an empty database and confirming all counts return 0.</verify>
  <acceptance_criteria>
    - `get_statistics()` executes aggregate SQL queries on SQLite.
