# Kalyan Hospital OPD reception banner

Three editable art directions are in [`index.html`](./index.html). The working assumption is a website hero at **1920 × 800 px**; the headline and copy are drafts because no exact banner copy or placement was supplied.

## Preview a direction

Open `index.html` in a browser at 100% zoom. Add one of these query parameters to the address:

- `?style=minimal` — light, spacious layout with a burgundy accent.
- `?style=bold` — burgundy field with large type and a token preview.
- `?style=editorial` — warm paper tones and a grid-led queue card.

All options use Kalyan’s burgundy, gold, and light surfaces, one CTA, a single system typeface, and content within the hero safe area. Queue labels are illustrative and contain no patient identities or live counts.
